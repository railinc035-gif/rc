Diccionario y Reglas

Reglas Oficiales de Sintaxis RC

  • Comandos e IDs: Los comandos se escriben en minúsculas. Los IDs entre corchetes solo admiten [a-z0-9_-].
  • Texto libre: Etiquetas, títulos y contenido visible admiten mayúsculas, tildes, signos, emojis y no requieren comillas.
  • Parámetros (): Encerrar argumentos en paréntesis (). Múltiples argumentos usan paréntesis consecutivos (arg1)(arg2).
  • Estructuras y grupos []: Usar corchetes [] cuando aplique para conjuntos o rangos de opciones.
  • Asignaciones (=): Signo igual = para asignaciones directas o configuraciones.
  • Comentarios (//): Usar doble barra // para comentarios de una sola línea.
  • Inclusión: Usar incluir(nombre) para importar archivos o módulos externos RC.
